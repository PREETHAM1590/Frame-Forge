## Visual language summary

- Palette: carbon blacks #050608/#090a0d/#0d0e11, alt cell #12141a, hover #20232d, wireframe borders #262930; text #f5f5f7 / #9ba0ad / #5e6370; primary safety orange #ff5500, caution amber #ffaa00, error red #ff3b30.
- Fonts: Space Grotesk 900 uppercase headings; JetBrains Mono for all telemetry, labels, tags and numerals (tabular).
- Shape/depth: 0px radius, no shadows; 1-2px #262930 borders, shared-border cells (0 gutter), top accent rules, alternating tile tones.
- Cards: mono uppercase label + status badge on top, large mono numeral, flat meter (h-2/3, orange fill); p-6/p-8; buttons are solid orange with black text or dark with bordered mono text.
- Nav: fixed 256-288px left rail with numbered rows (active = solid orange, black bold), Settings + chassis footer, fixed top telemetry bar with window controls.
