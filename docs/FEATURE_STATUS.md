# Feature Status

Status describes behaviour, not performance benefit. Every status is one of four values:

- **Implemented**: the feature exists and runs in the desktop app. The scope column states what was verified on the development PC and what was checked only with fixtures or fakes.
- **Implemented (needs admin)**: the feature runs, but its Windows operation requires a UAC prompt for each action.
- **Unsupported**: not offered. The reason is in the scope column.
- **Mocked (demo)**: browser demo data or a test-only adapter. Never a real Windows change.

"Verified on this PC" means run against the real Windows state of the development machine (Windows 11, build 26300). "Fakes" means xUnit or Vitest tests with fake registry, power, process or WMI stores. Nothing has been verified on a second machine.

## Windows System Restore

| Capability                       | Status                    | Scope or limitation                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| -------------------------------- | ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Create a Windows restore point   | Implemented (needs admin) | WMI `SystemRestore.CreateRestorePoint` in a helper that Windows elevates with `runas` per action. The new point is confirmed by a higher sequence number and its description. Declining UAC is reported as cancelled and changes nothing. Not verified on real hardware by a person: the elevated create path has not been run here, and `runas` has never been launched.                                                                                                                                                                                                       |
| System Protection check for C:   | Implemented (needs admin) | Checked through the per-drive protection record, which is only readable elevated. If that record cannot be read, C: is reported as unconfirmed rather than protected. A reading of "off" is only a warning before creating: Windows' own answer and the new restore point decide, and the result states when C: coverage reads as off or could not be confirmed. Only the `DisableSR` policy is treated as System Restore turned off; `DisableConfig` is not. Verified on this PC only for the unelevated status read (`enabled`, C:); the per-drive check is covered by fakes. |
| Turn on System Protection for C: | Implemented (needs admin) | Consent dialog first (it uses disk space). Success is reported only when Windows reads the drive back as enabled. Fakes only.                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| 24-hour creation limit           | Implemented (needs admin) | Windows allows one app-created point per 24 hours by default. The app reports the throttle and offers "Create anyway", which lifts the limit for that one creation and restores the original value afterwards (verified). Fakes only: this PC has the frequency at 0, so the throttle cannot be reproduced here.                                                                                                                                                                                                                                                                |
| Restore points list              | Implemented (needs admin) | Lists the points Windows reports, read through the elevated helper. The unelevated call on this PC returned the expected admin-required failure; the elevated read has not been run by a person.                                                                                                                                                                                                                                                                                                                                                                                |
| Open Windows System Restore      | Implemented               | Starts `rstrui.exe` from the System32 folder.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| App configuration backups        | Implemented               | Frameforge's own SQLite backups of settings, games and presets. Separate from Windows restore points and not a machine backup.                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
