# Game-booster feature catalog -> Frameforge mapping

Source list: a local, untracked list of 87 commonly offered game-booster features. Evidence grades: **A** documented by Microsoft (or NVIDIA for the DLSS key), **B** value present on the reference PC (Windows 11 Pro 26100, RTX 4050 laptop) and it is the setting the Windows UI itself writes, **C** community only.
Anything graded C or not confirmable is `[unverified]` and is **not applyable**.

Classes: `have` = already exists, `impl` = implement now (HKCU, no admin), `adv` = implement as Advanced opt-in (admin: HKLM / bcdedit / powercfg), `sec` = implement in the separate "Security trade-offs" category (user override of H4, extra guardrails below), `info` = information only, `no` = not offered, `dup` = duplicate of another row.

Finding from the real round trip on the reference PC: `HKCU\Software\Policies` is write-protected for a non-elevated user (the helper got "access denied"), so the four items that rely on a policy key (items 8, 23, 41, 46) use the machine policy hive and are Advanced administrator items instead of current-user items.

Common rules for every `impl`/`adv`/`sec` item: typed definition, exact settings, prerequisites, risk label, pre-change capture of the exact prior state (absent included), preview, confirmation, post-apply re-read, rollback to the exact prior state, Activity row, tests. Admin items use the helper's self-elevation (one UAC prompt per helper call, reads of HKLM need none). Nothing is run elevated during testing; admin code is exercised through fakes.

## Security trade-offs (user override of H4)

Items 21, 26, 29, 31, 36, 37, 40, 43, 44, 78, 79 are applyable only in the separate **Security trade-offs** category. Guardrails: off by default, in no preset, excluded from any multi-select apply; red High risk label with a plain-language consequence; confirmation needs the user to type the item name; restore-point offer in the preview; exact prior capture and rollback (absent included) re-read after both; "Pending restart" while a reboot-required item is applied; Dashboard banner with one-click "Restore all security settings"; the server refuses a confirm without the acknowledgement. Items 39 and 42 stay info-only [unverified]. Tamper Protection is only read, never bypassed. Never applied for real during development.

All come from the Game Mode allowlist and none is on the never-touch list (a test checks both). Core, security, network, audio, input, update and Xbox services are not offered. Refused when a running service depends on it. Blocked while Game Mode runs (apply and rollback).            |
| Disable Large Send Offloads            | `lso-off`                                                                                                                                                              | Standardized driver keywords `*LsoV2IPv4` and `*LsoV2IPv6` (strings under the adapter's driver key in the Network class). Found live for physical PCI or USB adapters whose driver already holds the value; never creates a value. The administrator step re-resolves the adapters itself, and rollback skips an adapter that is gone. The adapter driver reads it on restart. |
| Optimize NVIDIA Performance            | `nvidia-performance`                                                                                                                                                   | NVAPI DRS on the global base profile: `PREFERRED_PSTATE_ID` 0x1057EB71 = 1 (Prefer maximum performance) and `PRERENDERLIMIT_ID` 0x007BA09E = 1. Live verification on the reference PC (Windows 11 Pro 26100, RTX 4050): the helper read all of the above without writing; the LSO adapter (Realtek PCIe GbE, both properties present) and the NVIDIA profile interface were found. The NVIDIA settings were set, re-read and deleted for real (several times, while probing the interface and running the test): the immediate re-read after each delete matched the starting state (absent), but within seconds of a set-then-delete the driver wrote its own entries (power management 5, pre-rendered frames 0; not verified to be the driver defaults) into the profile. They were deleted by hand and the final read-back is absent. Only these two setting ids were compared; the driver database file was rewritten each time and no baseline of other entries exists. Services, the Photo Viewer capabilities, LSO and the Mobility Center policy were exercised with fakes only: nothing in HKLM, no service and no adapter was changed on this PC.

### Removed

| Item                                                                     | Why                                                                                                                                                                                                                                                                          |
| ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Optimize Device Affinities                                               | Microsoft documents the Affinity Policy values but names no optimal target (which cores). `AssignmentSetOverride` is binary, and every candidate on the reference PC (GPU, NIC, USB, storage controller) already carries a driver-set override that would be overwritten.    |
| Optimize Message Signal Interrupts                                       | `MSISupported` is documented, but every GPU, NIC, USB and storage device on the reference PC already reads 1, so there is nothing to change; a device that explicitly holds 0 is a driver INF decision and flipping it can leave the device or boot disk without interrupts. |
| Optimize Integrated Intel GPU, NVIDIA sharpening, privacy and telemetry  | No documented, verified setting was found for these (the two performance settings above are the only NVIDIA settings Frameforge writes).                                                                                                                                     |
| Optimize Network Performance, Optimize Storage and Memory                | Nagle, throttling, QoS and cache tweaks are placebo or harmful; Windows already manages these values.                                                                                                                                                                        |
| Disable Dynamic Interrupt Steering, Modern Windows Memory Management     | The exact kernel values are not documented.                                                                                                                                                                                                                                  |
| Optimize SMB, Disable VPN Support                                        | The change is not defined (SMB1 is already absent); no documented switch exists for VPN support.                                                                                                                                                                             |
| Unlock EU Privacy Mode                                                   | Region spoofing has no documented mechanism.                                                                                                                                                                                                                                 |
| Disable Live Tiles, HomeGroup, My People                                 | The features no longer exist in Windows 11 (HomeGroup was removed in version 1803).                                                                                                                                                                                          |
| Disable Lock Power Option                                                | The `FlyoutMenuSettings\ShowLockOption` key is absent on the reference PC and cannot be verified.                                                                                                                                                                            |
| Disable Lock Screen                                                      | The policy is honoured only on Enterprise and Education; the reference PC is Professional.                                                                                                                                                                                   |
| Disable Touch Settings, Disable Windows Focus Assist                     | No documented switch; Focus Assist is an undocumented binary blob.                                                                                                                                                                                                           |
| Increase Taskbar Transparency                                            | `UseOLEDTaskbarTransparency` is community-only, absent on the reference PC, and its effect cannot be verified without an HKLM write.                                                                                                                                         |
| Show All Taskbar Tray Icons                                              | `EnableAutoTray` is ignored by Windows 11.                                                                                                                                                                                                                                   |
| Disable Disk Quotas                                                      | Quotas are off by default and are set per volume.                                                                                                                                                                                                                            |
| Optimize Context Menu                                                    | A shell verb that launches Frameforge would embed the app's install path (it moves on update) and needs a new helper entry point; the verbs in the original run takeown and icacls. Not a simple reversible value.                                                           |
| Install Process Explorer / Enhanced Registry Editor, VALOFLANT promotion | Would download and install third-party software, or is a promotion, not a Windows optimization.                                                                                                                                                                              |
| Fax service on its own                                                   | Not installed on current Windows; covered by the Print Spooler item.                                                                                                                                                                                                         |

The four review-only rows (GPU scheduling review, startup app review, graphics driver review, DNS configuration) open the matching Windows Settings page and are marked "Review only" in the catalogue. They are the only entries without an Apply.
